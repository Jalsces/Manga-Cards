Comment installer

  1. Cliquez sur le bouton "Télécharger" ci-dessus
  2. Allez dans vos téléchargements
  3. Ouvrez le fichier "Jeu"
  4. Appuyez sur "Jeu", puis sur "Extraire tout", puis sur "Extraire"
  5. Retournez dans vos téléchargements
  6. Ouvrez le deuxième fichier
  7. Appuyez sur "Jeu"
  8. Une page va s'ouvrir : appuyez sur "Informations complémentaires", puis sur "Exécuter quand même"
